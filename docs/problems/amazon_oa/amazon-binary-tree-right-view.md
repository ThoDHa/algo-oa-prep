# [Binary Tree Right View](https://www.fastprep.io/problems/amazon-binary-tree-right-view)

**Medium** | **NN minutes** | **Tree, Breadth First Search, Depth First Search**

Given the root of a binary tree, imagine viewing the tree from its right side.Return the value of the visible node at each depth, ordered from the root level downward. For an empty tree, return an empty array.

## Examples

### Example 1

**Input:** `root = [1,2,3,null,5,null,4]`

**Output:** `[1,3,4]`

**Explanation:** The rightmost visible values at successive levels are 1, 3, and 4.

### Example 2

**Input:** `root = [1,null,3]`

**Output:** `[1,3]`

**Explanation:** The right child is visible below the root.

### Example 3

**Input:** `root = []`

**Output:** `[]`

**Explanation:** An empty tree has no visible levels.

## Constraints

- `The tree contains between 0 and 10000 nodes.-10^9 <= Node.val <= 10^9.`
