# [Optimal Level](https://www.fastprep.io/problems/amazon-find-optimal-level)

**Hard** | **NN minutes** | **Array, Binary Search, Greedy**

$23

## Examples

### Example 1

**Input:** `stockArr = [11, 1, 2]`
**Input:** `incVal = 2`
**Input:** `decVal = 3`

**Output:** `3`

### Example 2

**Input:** `stockArr = [1, 5, 9]`
**Input:** `incVal = 2`
**Input:** `decVal = 2`

**Output:** `5`

## Constraints

- `2 ≤ n ≤ 2*10^5`
- `1 ≤ stockArr[i] ≤ 10^9`
- `1 ≤ incVal ≤ decVal ≤ 10^9`
