# [Three Sum Closest](https://www.fastprep.io/problems/amazon-three-sum-closest)

**Medium** | **NN minutes** | **Array, Sorting, Two Pointers**

Given an integer array nums and an integer target, choose three distinct indices and return the sum of their values that is closest to target.If two obtainable sums are equally close, return the smaller sum.

## Examples

### Example 1

**Input:** `nums = [-1,2,1,-4]`
**Input:** `target = 1`

**Output:** `2`

**Explanation:** The closest sum is -1 + 2 + 1 = 2.

### Example 2

**Input:** `nums = [0,0,0]`
**Input:** `target = 1`

**Output:** `0`

**Explanation:** The only possible sum is 0.

### Example 3

**Input:** `nums = [-2,0,2,4]`
**Input:** `target = 1`

**Output:** `0`

**Explanation:** Sums 0 and 2 are both one away, so the smaller sum 0 is returned.

## Constraints

- `3 <= nums.length <= 1000.-10^4 <= nums[i], target <= 10^4.The answer fits in a signed 32-bit integer.`
