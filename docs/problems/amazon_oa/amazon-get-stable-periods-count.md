# [Get Stable Periods Count](https://www.fastprep.io/problems/amazon-get-stable-periods-count)

**Medium** | **NN minutes** | **Sliding Window, Hash Table**

$23

## Examples

### Example 1

**Input:** `revenues = [1, 2, 1]`
**Input:** `k = 1`

**Output:** `3`

**Explanation:** There are 3 periods with k=1 or fewer distinct values. The number of stable growth periods is 3.

### Example 2

**Input:** `revenues = [2, -3, 2, -3]`
**Input:** `k = 2`

**Output:** `10`

**Explanation:** Any contiguous period of 1 or more days has 2 or fewer distinct values, thus all 10 subarrays represent a period of stable growth 📈📈

## Constraints

- `1 ≤ n ≤ 10^51 ≤ k ≤ n-10^9 ≤ revenues[i] ≤ 10^9`
