## Examples

### Example 1

**Input:** `x = 3`
**Input:** `y = 4`
**Input:** `n = 13`

**Output:** `4333`

**Explanation:** If the two digits that make up the number are x = 3 and y = 4, and the sum of the digits must be n = 13, then the lucky numbers are:
      
        3334334334334333
    
The maximum lucky number is 4333.
