## Examples

### Example 1

**Input:** `expense = [1, 2, 3, 2, 5]`
**Input:** `p = 3`

**Output:** `[14, 18]`

### Example 2

**Input:** `expense = [1, 2, 3, 4]`
**Input:** `p = 2`

**Output:** `[12, 8]`

**Explanation:** Answer : Max = 12
[1+3,4+4] First Partition Is From Index 0 To 2 , second From 3 To 3

Min = 8
[1+1,2+4] First Partition From Index 0 to 0 , second From 1 To 3
